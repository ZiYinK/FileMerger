# FileMerger

一个轻量级的 C# 控制台工具，用于将指定文件夹（含子目录）下的所有 `.cs` 源文件智能合并为单个文件。适用于代码提交、AI 上下文投喂、代码审计或归档等场景。

## ✨ 功能特性

- **递归扫描**：自动遍历目标文件夹及所有子目录中的 `.cs` 文件
- **智能去重 using**：自动提取并合并所有 `using` / `global using` 指令，去除重复项
- **来源注释标记**：在每个 `class` / `struct` 声明前自动插入来源文件路径注释，便于追溯
- **自动过滤**：自动忽略 `bin`、`obj`、`.git`、`.vs` 等构建/IDE 目录，以及已生成的 `Merged*.cs` 文件
- **词法感知解析**：正确处理字符串字面量、字符字面量、注释中的关键字，避免误匹配
- **XML 文档 & Attribute 保留**：在类型声明前插入来源注释时，自动跳过紧贴的 XML 文档注释 (`///`) 和特性 (`[...]`)，保持代码结构完整
- **UTF-8 BOM 输出**：生成带 BOM 的 UTF-8 编码文件，兼容 Windows 环境
- **依赖**：纯 .NET 标准库实现，无需任何第三方 NuGet 包


## 🚀 使用方法

运行FileMerger.exe，程序会提示输入文件夹路径：

```
=== C# 源文件合并工具 ===
请输入文件夹路径:
```

> 💡 路径支持拖拽文件夹到控制台窗口自动填入，两端引号会被自动去除。

## 📄 输出说明

- 输出文件命名格式：`Merged - yyyy-MM-dd HH-mm-ss.cs`
- 输出位置：与输入的源文件夹同级目录下
- 文件头部包含 `<auto-generated>` 标记及生成时间戳
- 每个类型声明前标注原始相对路径，例如：

```csharp
//====================
//来自于Services\UserService.cs

public class UserService { ... }
```

## ⚙️ 工作原理

1. 递归收集目标目录下所有 `.cs` 文件（排除忽略目录和已有合并文件）
2. 逐文件解析：提取 `using` 指令 → 移除 using → 定位 `class`/`struct` 声明并插入来源注释
3. 全局去重 using 指令，按序拼接所有文件体
4. 添加自动生成头注释，写入带 BOM 的 UTF-8 文件

## ⚠️ 注意事项

- 本工具仅处理 `.cs` 文件，不支持其他语言
- 合并后的文件不包含 `namespace` 块的重构，请确保原文件的命名空间不会冲突
- 建议在使用前备份原始代码
- 如遇到读取权限问题，程序会自动跳过该文件并在控制台提示
